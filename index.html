使用說明

共通操作

  • 在首頁點「📄 選擇 PDF 檔案」或直接把 PDF 拖進視窗，載入後點「🟡 底線導讀」或「✎ 自訂語音」即可開始。
  • 工具列「▶ 試播」試聽本頁朗讀，「❚❚ 暫停」暫停；「↻ 重播」重播目前頁；「🏠 返回首頁」可隨時回首頁切換模式。
  • 鍵盤：空白鍵＝播放／暫停、← →＝換頁、F＝全螢幕、R＝重播、Esc＝關閉彈窗／停止。
  • 點「▶ 試播」或「▶ 播放並錄影」會自動進入全螢幕，PDF 自動置中；停止播放即回到瀏覽器。
  • 全螢幕時僅右上角保留「✕ 回到瀏覽器」按鈕，其餘工具列、縮放與翻頁按鈕一律隱藏。
  • 字幕隨語音逐字即時同步顯示，底部深色底框（95% 不透明），已朗讀的字以金色高亮。

模式一：底線導讀

  • 自動偵測 PDF 中的底線文字並朗讀，黃色遮罩與字幕隨語音同步。
  • 語音會略過文章中的標點與表情符號（例如「;D」只唸「D」），避免誤念；字幕仍顯示原文。
  • 「▶ 播放並錄影」：一邊播放一邊錄製畫面與語音，播到最後一頁自動停止並下載影片（WebM）。

模式二：自訂語音

  • 為每一頁自行輸入要朗讀的文字，作為語音與字幕來源。
  • 左側為該頁 PDF 預覽，右側輸入文字並即時預估秒數；留空則該頁 1 秒後自動翻頁。
  • 「▶ 確認並播放」開始播放；「🎥 錄影並播放」同時錄製畫面與語音。

錄影注意事項

  • 請使用 Chrome 或 Edge。點「▶ 播放並錄影」後瀏覽器會要求分享畫面與音訊，請允許並選擇「Chrome 分頁」（本頁）。
  • 影片由程式直接合成（頁面＋黃色高亮＋字幕），不受「語音不會被錄進分頁畫面」的瀏覽器限制影響。
  • 語音經系統音訊或麥克風收錄：分享時建議勾選「分享系統音訊」（Share system audio），若無系統音訊會自動改用麥克風。
  • 字幕已直接燒錄進影片，輸出的影片即使離開本頁也能看到逐字字幕與高亮。
  • 輸出為 WebM（VP9／Opus）格式，含語音；播放途中按「⏹ 停止」或 Esc 可提前結束並下載。
